## Goal

The air-gap rehearsal of 14 Oct (gate C: "internetsiz kurulum temiz VM'de < 30 dk") found that
the documented bundle build cannot succeed. `build-bundle.sh` pulled `ghcr.io/vigil-soc/vigil-*`,
but `release.yml` publishes `ghcr.io/singularityrd/autosecops-{backend,daemon,agent}`, the names
the W4.7 contract fixes. With `--image-namespace` set to the release namespace, the bundle pushed
the images there but shipped `values-airgap.yaml` with the old namespace, so every app pod would
pull a path that the local registry does not hold. After this WP, every default (Helm
`global.imageNamespace`, `airgap_images.py`, `values-airgap.yaml`, the desktop compose file and its
scripts, and README/SECURITY/CHANGELOG/release-notes examples) names the release images. A test
derives the expected names from `release.yml` (`IMAGE_PREFIX` plus the build matrix), so the names
cannot drift again. `--image-namespace` is carried into the bundled overlay. A failed build removes
its partial bundle, so a rerun is not refused with "already exists". The Ollama model pull gets the
build machine's proxy settings (and an optional CA), and it uses the `--ollama-image` override. The
README (§2) and the guide (§3) say how the operator obtains the app images: the signed release
images, verified with `verify-release.sh`, then checked against the signed `images.json`.

- Changing `release.yml` or publishing images; `docs/ci.md` and the release-please row.
- Publishing Medic images (`medic.enabled` derives `<registry>/<namespace>-medic`, still unpublished).

## Evidence

- Rehearsal logs (14 Oct, this machine, not a clean VM): signed bundle built in 32 s with stand-in
  app archives; `install.sh verify` took 7 s; load+push of 8 images to a local `registry:2` took
  ~11 s; 8/8 tamper cases were refused before any docker/kubectl/helm call.
  Kubernetes could not run containers here (kind 0.24/0.30, k3s 1.31: `runc create failed: can't
  get final child's PID from pipe: EOF`).
- Commit(s): see branch `wp/w0.21-airgap-fixes`.

## Risk

  check need a real clean VM with the tagged, signed release images; this WP only removes the
  blockers that the rehearsal found.

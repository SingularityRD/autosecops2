## Goal

Üç açık kapanır. (1) W4.3 F-1 (Kritik): `POST /api/detection-rules/sources`
artık `settings.write` ister (Viewer/Analyst/Senior Analyst 403 alır) ve bir git
kaynağı yalnızca `https://host/yol` olabilir; `ext::`, `file:`, `ssh`, `git://`,
`http://`, `-` ile başlayan değer, kimlik bilgisi/sorgu/parça içeren URL 400 ile
reddedilir, git hiç çalışmaz. Ana makine iç/özel/metadata adresine çözülen host
(SSRF) reddedilir (`VIGIL_DETECTION_GIT_ALLOWED_CIDRS` ile iç git sunucusuna izin
verilebilir; metadata yine reddedilir). Her git çağrısı `--` ayırıcı,
`GIT_ALLOW_PROTOCOL=https`, `GIT_TERMINAL_PROMPT=0`, `-c protocol.ext.allow=never`,
`-c protocol.file.allow=never`, `-c http.followRedirects=false`,
`--no-recurse-submodules`, zaman aşımı ve kontrol edilen adrese sabitleme
(`http.curloptResolve`) ile çalışır; `detection_sources.json` içinde W0.11'den
önce saklanmış bir URL veya mevcut bir klonun `origin`'i de aynı kontrolden geçer.
(2) W0.10 doğrulayıcı (Orta): `regulatory_clock_heads` ve `regulatory_clock_events`
TRUNCATE'i bir BEFORE TRUNCATE deyim tetikleyicisiyle reddeder;
`verify_chain` başlık tablosu yoksa `{"ok": false, "why": "chain head unavailable"}`
döner (başlık satırı eksikse zaten `chain head missing`); API `ChainResponse`
`anchored` alanını taşır, arayüz satır numarası olmayan hatayı ve çapasız
doğrulamayı gösterir; gerçek sınır (tablo sahibi/süper kullanıcı) belgelenir.
(3) W4.3 F-2: Viewer'ın erişebildiği, açıkça yanlış olan durum-değiştiren rotalar
mevcut izinlerle kapılanır; `auth_only_write_routes.txt` küçülür, kalanların
gerekçesi dosyada yazılıdır.

## Non-goals

- Yeni RBAC izni veya rol tohumu değişikliği (yalnızca mevcut izinler kullanılır).
- Arayüzde izne göre buton gizleme (sunucu 403 döner; UI ayrı iş).
- Tablo sahibi / süper kullanıcıya karşı koruma (belgelenmiş sınır).
- W4.3 dalının `route_role_matrix.json` dosyasını güncellemek (o dal birleşmemiş;
  birleşince matris bu kapıları yansıtacak şekilde yeniden üretilmeli).
- git'in kendi DNS çözümlemesi ile kontrol arasındaki yarış için tam pinleme
  garantisi (proxy kullanan kurulumlarda `curloptResolve` etkisizdir).

## Risk

- Tier: Yüksek
- Rationale: yetkilendirme (RBAC kapıları), komut çalıştırma sınırı (git alt
  süreci), dış ağ çıkışı (SSRF) ve DB şeması (tetikleyiciler).
- Rollback: `git revert -m 1 <merge-sha>`. Şema: `DROP TRIGGER regulatory_clock_heads_no_truncate ON regulatory_clock_heads; DROP TRIGGER regulatory_clock_events_no_truncate ON regulatory_clock_events; DROP FUNCTION regulatory_clock_no_truncate();`

  onun üzerinden SQL enjeksiyonu) karşı tespit sağlar; tetikleyicileri DROP /

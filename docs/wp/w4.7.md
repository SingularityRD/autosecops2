## Goal

`v*` etiketi `SingularityRD/autosecops2` reposuna itildiğinde `.github/workflows/release.yml`
backend, daemon ve agent imajlarını (linux/amd64 + arm64) ve web konsolunun statik
paketini (`autosecops-<V>-web.tar.gz`) üretir; Python (`requirements.lock`) ve Node
(`clients/web`, `services/agent`, `infra/docker/mcp-packages`, `clients/desktop`)
lockfile'larından ve her imajdan (syft) CycloneDX SBOM'ları çıkarır; imajları cosign ile
anahtarsız (keyless, GitHub OIDC) imzalar, her imaja CycloneDX SBOM ve SLSA v1 provenance
attestation'ı ekler, tüm sürüm dosyalarını `SHA256SUMS` + Sigstore bundle'larıyla imzalar
ve GitHub Release'e ekler. Aynı lockfile SBOM'larını internetsiz üreten yerel bir kuru
çalıştırma (`scripts/release/dry-run.sh`) vardır. `VERSION` ve sürümü taşıyan tüm
dosyalar `2.0.0` olur; `CHANGELOG.md`'de 2.0.0 girdisi, `docs/release/2.0.0.md`'de
birleşen / birleşmeyen WP'leri ayıran Türkçe sürüm notları, `VERSIONING.md`'de etiket
süreci, `docs/release/dogrulama.md`'de müşterinin imzaları ve SBOM'ları internetsiz
(air-gap) doğrulama rehberi bulunur. **`v2.0.0` etiketi bu WP'de oluşturulmaz.**

## Non-goals

- `v2.0.0` (veya rc) etiketini oluşturmak / itmek; GitHub Release yayımlamak.
- Helm chart varsayılan `global.imageNamespace` değerini (`vigil-soc/vigil`) değiştirmek:
  air-gap paket testleri bu varsayılana bağlı (W3.3). 2.0.0 kurulumunda
  `--set global.imageNamespace=singularityrd/autosecops` / `build-bundle.sh
  --image-namespace singularityrd/autosecops` kullanılır (sürüm notlarında yazılı).
  Varsayılanın değişmesi ayrı bir takip işi.
- Ayrı bir web imajı (nginx vb.): SPA backend imajının içinde servis edilir
  (`Dockerfile.backend` web-builder aşaması); web için imzalı statik paket + SBOM üretilir.
- release-please iş akışını etkinleştirmek (hâlâ upstream korumalı); yalnızca manifest
  sürümü senkron tutulur.
- Bağımlılık ekleme: `scripts/release/` yalnızca Python standart kitaplığı + POSIX sh.

## Risk

- Tier: Yüksek
- Rationale: CI değişikliği; imzalama kimliği (OIDC `id-token`), registry'ye yazma ve
  GitHub Release'e yazma yetkileri içeriyor. Anahtarsız imzalama, depo adını ve iş akışı
  yolunu herkese açık Sigstore şeffaflık kaydına (Rekor) yazar — özel depo için bu bir
  bilgi ifşasıdır; sürüm yöneticisi etiketlemeden önce kabul etmelidir
  (`docs/release/dogrulama.md` §"Gizlilik notu").
- Rollback: `git revert -m 1 <merge-sha>`; yayımlanmış bir sürüm için ilgili GHCR
  etiketleri ve Release silinir (imzalar Rekor'da kalır).

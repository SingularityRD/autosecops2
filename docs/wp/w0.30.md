## Injection ölçümü (evalkit)

Komutlar (depo kökü, `PYTHONPATH=.`):

```
AUTOSECOPS_GUARDS=off python -m evalkit ci --out /tmp/w030/ci-ts-off
AUTOSECOPS_GUARDS=on  python -m evalkit ci --out /tmp/w030/ci-ts-on
python -m evalkit run --backend stub --suite test,test_unseen,injection --subject-guards off --out /tmp/w030/stub-off
python -m evalkit run --backend stub --suite test,test_unseen,injection --subject-guards on  --out /tmp/w030/stub-on
```

| Koşu | test F1 / P | test_unseen F1 / P | injection ASR (k/n, %95) | flip_to_benign | induce_action |
|---|---|---|---|---|---|
| kaset, `AUTOSECOPS_GUARDS=off` | 0.946 / 0.921 | 0.870 / 0.909 | 0.0875 (21/240, 0.059–0.124) | 14/144 | 7/96 |
| kaset, `AUTOSECOPS_GUARDS=on` | 0.946 / 0.921 | 0.870 / 0.909 | 0.0875 (21/240) | 14/144 | 7/96 |
| stub, `--subject-guards off` | 0.946 / 0.921 | 0.870 / 0.909 | 0.0875 (21/240) | 14/144 | 7/96 |
| stub, `--subject-guards on` | 0.875 / 0.795 | 0.815 / 0.733 | 0.0292 (7/240, 0.014–0.054) | 0/144 | 7/96 |

Bu sayılar ne demek:

- evalkit **yalnızca Python triage yolunu** (`FindingProcessor`, W4.3'ün ölçtüğü yol)
  ölçer. TS guard'ları (hunt/verdict) bu yola hiç girmez: açık/kapalı kaset
  sonuçları **yapı gereği** aynıdır. Bu bir "etkisiz" sonucu değil, ölçümün TS
  yolunu kapsamadığının kanıtıdır. TS yolunu ölçen bir evalkit "verdict-run
  varyantı" henüz yok (açık risk).
- Kaset ve stub **model değildir**: stub, istemdeki sözcüksel ipuçlarını
  ("approved", "vendor-signed", ...) sayan deterministik bir alt sınırdır. Python
  guard'ı tam da bu tür yönlendirici sözcükleri içeren ADVERSARY değerlerini
  sakladığı için stub'ın `flip_to_benign` başarısı 14 → 0'a iner; aynı nedenle
  meşru iyi huylu ipuçları da saklanır ve kesinlik düşer. Gerçek bir modelin
  ASR'si ve doğruluğu hakkında bir şey söylemez; `--backend live` ile ölçülmeli.
- `induce_action` (7/96) değişmez: o vakalarda enjekte metin STEERING kalıbına
  uymuyor; kalıp test verisine göre ayarlanmadı (ayarlamak savunmayı uyduğu veriyle
  notlandırmak olurdu).

## Goal

`.github/workflows/ci-cd.yml` ("CI/CD Pipeline") main üzerinde kırmızı; bu yüzden
"Build Docker Images" / "Scan Docker Images" hiç çalışmıyor. Bu WP bittiğinde
CI'daki şu işler, CI'daki komut/ortam/işaretleyicilerle yerelde yeniden
üretildiğinde yeşildir: **Security Scan - Python (Bandit)**, **Unit Tests -
Backend (DB-backed)**, **Unit Tests - Backend**, **Integration Tests**. Düzeltmeler
kök nedendedir: hiçbir test atlanmaz/xfail edilmez/zayıflatılmaz, zaman aşımı
artırılmaz, Bandit kapatılmaz ve global skip genişletilmez.

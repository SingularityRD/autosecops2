# WP W0.20 — Docs merged-list check against the documented base

| Field | Value |
|---|---|
| Risk | Normal (test-only) |
| Allowed files | `tests/unit/docs/test_guide_docs.py`, `docs/wp/w0.20.md` |
| Forbidden files | everything else |

## Goal
`test_merged_list_matches_git` compared `merged_wps.txt` with `HEAD`, so every WP merged after the
docs were written (W0.18, W0.19, W4.7, ...) broke `main` until the docs were edited. The pages state
the commit they describe (`main` @ `<sha>`); the list is now checked against that commit. A branch
merged later is simply not documented yet; a listed branch must still be merged into the base, and a
branch merged into the base must still be listed. Falls back to `HEAD` when the pages name no single
resolvable base (the one-base test fails in that case anyway).

## Acceptance criteria
| AC | Command | Expected |
|---|---|---|
| AC1 | `pytest tests/unit/docs` on integration with W0.18 merged after the base | all pass |
| AC2 | drop a branch merged before the base from `merged_wps.txt` | `test_merged_list_matches_git` fails |
| AC3 | add `wp/w0.18-ga-followups` (merged after the base) to `merged_wps.txt` | `test_merged_list_matches_git` fails |
| AC4 | `scripts/wp/gates.sh --base integration` | `RESULT: PASS` |
